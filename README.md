# Meow Smash 🐱

Derrube os objetos que chegam pela esteira, escape da dona e do cachorro ladrão e vire o gato mais esperto do ranking!

## Jogar

- **No navegador ou no celular:** https://meowsmash.vercel.app (no celular, use "Adicionar à tela inicial")
- **No Windows:** baixe o **MeowSmash.exe** na página de [Releases](../../releases/latest) e abra. É um arquivo só, não precisa instalar.
  - Se quiser atalhos, baixe o `.zip` e rode o `Instalar.bat`.
  - Na primeira vez o Windows pode avisar "O Windows protegeu o seu PC": clique em *Mais informações → Executar assim mesmo* (o programa não tem assinatura digital).
- Precisa de internet: a conta (e-mail, nick e senha) e o ranking ficam online.

Este repositório guarda só as versões para download. O jogo avisa no menu quando sai uma versão nova.
